Valid Vault Enterprise

Valid Vault Enterprise01 / 11

Company logins for every employee, without handing out the passwords

The passwords stay encrypted on the company's own equipment, with no vendor server and no server to run.

The problem02 / 11

Shared passwords end up in spreadsheets, texts, and someone else's server

  • Small businesses pass logins around by text, email, and spreadsheet.
  • Business password managers keep every customer's vault on the vendor's servers. In 2022, attackers stole encrypted copies of LastPass customer vaults.
  • Keeping it in-house today means running and securing your own password server.
What it does03 / 11

The admin decides who gets which logins. Employees unlock and fill.

  • The admin adds each employee's device and chooses which shared vaults it can open.
  • Employees unlock with a fingerprint or password and fill logins in the browser.
  • Removing a device locks the shared vault with a new key that device never receives.
  • Companies can choose network-only access, so company passwords work only on the office network.
How it is built04 / 11

Nothing central to attack

  • No server, no database, and no login page.
  • The browser extension is blocked from making any network connection.
  • Shared vaults are encrypted files on the company's own drive. The keys inside are locked to each device, so there is nothing in them a password guess can open.
  • It uses the file sharing and device management the company already runs.
Key protection05 / 11

Built to outlast guessing

  • Every vault is encrypted with AES-256-GCM.
  • Master passwords need 12 characters and go through 600,000 rounds of key derivation for every guess.
  • Fingerprint and Android unlock are bound to the device's security hardware, so stolen data has nothing to guess.
  • The encrypted key backup checks a passphrase and three security answers as one secret. A wrong guess never says which part was wrong.
Live today06 / 11

Shipping, with public source code

  • On the Chrome Web Store, one listing for Chrome, Brave, and Edge.
  • Android app built from the same code, with the Google Play release in testing.
  • More than 190 automated tests run on every change.
  • User guide, privacy policy, and security contact published.
In development07 / 11

Shared company vaults

  • Admin settings signed by the company's own key and pushed through Chrome and Android device management.
  • Device enrollment by short code, and removal by re-keying the shared vault.
  • Recovery and other sensitive actions approved by several executives, not one person.
  • Options for network-only access and wiping a device after repeated wrong unlocks.
Who it is for08 / 11

Businesses that answer for where their data sits

  • Clinics and medical offices
  • Law and accounting firms
  • Banks and credit unions
  • Defense suppliers
  • Utilities
  • Government offices
Business model09 / 11

Per-user licenses with a setup fee

  • Starting at $7 per user per month, billed yearly.
  • A one-time setup fee per business covers configuration and first deployment.
  • The personal version of Valid Vault stays free.
