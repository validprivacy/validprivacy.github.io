Products

Valid Vault

Available

A password manager for Chrome, Brave, Edge, and Android. Logins, two-factor codes, personal details, crypto wallet seed phrases, and bookmarks are encrypted on the device and move between your devices by QR code or encrypted file.

  • Fingerprint, device PIN, or password unlock
  • Autofill in the browser and in Android apps
  • A private browser on Android with tracker blocking
Learn about Valid Vault

Valid Symphony

Prototype

Touchless home control. A 60 GHz radar follows a raised hand inside a small control zone, and the lights respond, with everything running on the home network.

  • Radar only, with no camera or microphone
  • Hand positions are held in memory for a fraction of a second
  • Works with lights you already own, starting with LIFX

How we build

The same commitments apply to every product.

Your data stays with you

Valid Vault syncs device to device with no server in between. Valid Symphony's hub runs on your home network and keeps nothing on disk.

Claims you can check

Source code, automated tests, changelogs, roadmaps, and the reasoning behind design decisions are all public.

Few dependencies

Third-party code is copied into each repository and reviewed, so a release does not change because someone else's package did.

Security work first

Sensitive features ship only after their own security review. Card storage, for example, waits until that work is done.

The Valid Foundation

An independent home for the network

Valid Network, the Layer 1 blockchain underneath the wider Valid ecosystem, is being placed under the Valid Foundation, a non-profit organized to steward the network independently of any company, including Valid Privacy.
