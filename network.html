Valid Network

A 100% American-engineered blockchain, secured by validators worldwide.

A Layer 1 network written from scratch in Rust, designed to run on modest hardware with light consensus. It will be stewarded by the Valid Foundation, a non-profit being organized to hold the network independently of any company, including Valid Privacy.

How the network works

Three-Party Integrity

An original consensus mechanism. Three validators are drawn at random for each block, hash it independently, and finalize it on two-of-three agreement in under a second.

Standing earned by work

Validators build standing by producing correct blocks. A mismatch costs standing and places the validator in quarantine, and a backup steps in for one that fails to respond.

Modest hardware

A node is a single program that holds chain state in memory and runs in 2 GB of RAM, so a Raspberry Pi class computer can take part.

Network privacy

The network is built to keep as little about its participants as possible.

  • Peers are identified by a salted hash of their address, and the salt rotates every 24 hours, so raw IP addresses are never stored as identity.
  • All peer connections use TLS 1.3 with certificates generated in memory at startup.
  • Operators can pin the certificates of peers they trust.
  • Connection and message rate limits protect each node, and one validator per address resists Sybil attacks without a staking minimum.

Status

The network is in testnet development. Bootstrap peers are announced on Discord before each testnet launch.

Testnet announcements

Complete

  • Three-Party Integrity consensus with standing, quarantine, and backup validators
  • Peer-to-peer networking with discovery, gossip, and sync from peers
  • TLS 1.3 transport and hashed, rotating peer identity
  • Mempool, Ed25519 signatures, a command-line wallet, an RPC interface, and a metrics dashboard
  • Six-hour archive segments published to Arweave

In development

  • A live testnet with bootstrap nodes and validator onboarding
  • An observer period for new validators before promotion
  • Formation of the Valid Foundation and its board
Stewardship

The Valid Foundation

The Valid Foundation is being organized as a non-profit with its own board. It will hold Valid Network and fund its development and its community, independently of Valid Privacy or any other company that builds on the network.

Keeping the network and the company apart means the network does not depend on any one business, and anyone can build on it on equal terms.
