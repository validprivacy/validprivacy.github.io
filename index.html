How the gesture works
  1. ZoneThe radar watches a small, invisible zone in front of it.
  2. GrabHold a hand still for half a second, and the light dips to confirm.
  3. AdjustRaise or lower your hand to set the brightness.
  4. ReleasePull away and the light stays where you left it.

Walking through the room changes nothing. Only a deliberate gesture does.

Products

Valid Network

Flagship

A Layer 1 blockchain written from scratch in Rust, now in testnet. Three-Party Integrity consensus draws three validators per block for sub-second finality, and a node runs in 2 GB of RAM.

  • Validator standing earned through time and behavior, with no stake required
  • Raw IP addresses are never stored as peer identity
  • Chain history archived to Arweave in 6-hour segments

Valid Vault

Out now

A password manager for Chrome, Brave, Edge, and Android. Logins, two-factor codes, personal details, crypto wallet seed phrases, and bookmarks are encrypted on the device and move between your devices by QR code or encrypted file.

How we build

The same commitments apply to every product.

Your data stays with you

Valid Vault syncs device to device with no server in between. Valid Symphony's hub runs on your home network and keeps nothing on disk. Valid Network never stores raw IP addresses as identity.

Claims you can check

Source code, automated tests, changelogs, roadmaps, and the reasoning behind design decisions are all public.

Few dependencies

Third-party code is copied into each repository and reviewed, so a release does not change because someone else's package did.

Security work first

Sensitive features ship only after their own security review. Card storage, for example, waits until that work is done.

The Valid Foundation

Long-term stewardship for the network

Valid Network, the Layer 1 blockchain at the center of the Valid ecosystem, is built by Valid Privacy. The network will be placed under the Valid Foundation, a non-profit being organized to give validators and builders a lasting home for the protocol, once it is formed.
